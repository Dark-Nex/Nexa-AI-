# NexaAI — Premium AI Chatbot SaaS Platform

NexaAI is a high-performance, dark-mode real-time AI Chatbot Web Application designed with a glassmorphic aesthetic. Built using React, Vite, and Netlify Serverless Functions to securely connect with AI APIs.

## Features
- ⚡ **Secure API Architecture**: Zero client-side API Key exposure via Netlify Functions.
- 🎨 **Glassmorphism SaaS UI**: Cyberpunk-inspired dark design system with fluid typography.
- 💬 **Conversation Management**: Chat history stored in `localStorage`, create, search, rename, and delete sessions.
- 💻 **Markdown & Code Highlighting**: Full Markdown rendering with syntax-highlighted code containers and one-click code copy.

## Deployment to Netlify

1. Push your repository to **GitHub**.
2. Connect your GitHub repository to **Netlify**.
3. Go to **Site Configuration** > **Environment Variables**.
4. Add key: `AI_API_KEY` with your official API Key (e.g. Google Gemini API Key).
5. Deploy Site!
